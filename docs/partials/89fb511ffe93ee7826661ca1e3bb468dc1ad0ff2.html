🔗Requirements

Bowdy requires Nim >= 2.0.0. Read the Nim installation guide if you don't have Nim installed.

🔗Install with nimble

nimble install bowdy

🔗Install with clue

Or use clue, an alternative package manager for Nim development:

clue install bowdy --build

🔗Prebuilt binaries

Prebuilt binaries for Linux, macOS, and Windows will be published via GitHub Actions soon. Until then, please build from source using one of the methods above.

🔗Verify the installation

bowdy -h

Next, read the Syntax guide and compile your first stylesheet:

bowdy c style.bass -o style.css
